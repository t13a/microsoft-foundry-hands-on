# 架空データ: 出茂市 (でもし)

架空の政令指定都市「出茂市」のカテゴリとサービスのデータです。サイトと AI エージェントが同じ CSV を読みます。形式と制約は [要求仕様書](../docs/requirements.md) の 6 章のとおりです。

| ファイル | 内容 |
|---|---|
| `categories.csv` | カテゴリ (最大 3 階層、説明は Markdown) |
| `services.csv` | サービス (末端のカテゴリに属する) |

どちらも BOM 付き UTF-8 です。Excel で開いて編集できます。表示順は行の順です。

## 区の一覧

| 区 | 読み | 主な町 |
|---|---|---|
| 中央区 | ちゅうおうく | 本町、錦町、駅前 |

| 東区 | ひがしく | 旭町、日の出町、朝霧 |
| 南区 | みなみく | 港町、汐見町、南浜 |
| 西区 | にしく | 桜台、夕陽ケ丘、西野 |
| 湖畔区 | こはんく | 水辺町、白鷺、湖南 |
| 星見区 | ほしみく | 星見ケ丘、天文台、流星町 |

市役所本庁舎は中央区本町1-1-1 にあります。

## 架空であることの約束

- 住所は「区 + 町 + 番地 + 建物名」の形で、市名は書きません (例: `中央区本町1-2-3 保健センター`)。
- 電話番号は `000-XXX-XXXX` の形です。市外局番が `000` の番号は存在しません。
- ホームページ URL は `example.com` のサブドメインです (`www.city.demoshi.example.com` など)。

## 確認用に入れてあるケース

| ケース | データ |
|---|---|
| 総合案内窓口 (F-DAT-42) | `届出・証明 › 窓口案内` の「総合案内窓口」 |
| 同じ施設の複数の窓口 (F-DAT-43) | 各区役所 (市民課、保険年金課、介護保険係など)、市役所本庁舎の各課、中央区保健センター (予防接種相談窓口、定期予防接種など) |
| 親が異なる同名のカテゴリ (F-DAT-44) | 「相談窓口」(子育て・教育、健康・医療、福祉・介護、住まい・暮らし)、「予防接種」(子育て・教育 › 健診・予防接種、健康・医療)、「保険料・給付」(介護保険、国民健康保険) |
| 末端が 2 階層目のカテゴリ | 「手当・助成」「相談窓口」「上下水道」「戸籍」など |
| デザイン案の例 | `子育て・教育 › 健診・予防接種 › 予防接種` の「予防接種相談窓口」(`中央区本町1-2-3 保健センター`、`000-123-4567`) |
